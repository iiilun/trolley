# Trolley

十關電車問題。只有圓點、細線、留白與選擇。

原生 HTML、CSS、JavaScript，沒有外部資源或建置步驟。直接開啟 `index.html`，或在此資料夾執行：

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

開啟 http://127.0.0.1:4174。

## 設計與操作

- 首頁只保留 logotype、問題與輸入欄。輸入自己的名字後按 Enter，再輸入親密家人或朋友的名字。
- 情境說明為黑底，只有短情境、兩種後果與小型動畫；點畫面或按 Enter 開始。實際操作為白底。
- 全部採平面視角。人為小圓點，車為大圓點；軌道上的人沿軌道橫向排成一列。胖子較大，惡棍多一圈細線，親人的名字緊貼對應圓點上方。
- 拉桿／AI 方向控制器在下方中央，可點按或拖動切換；12 秒決策時間結束後鎖定方向。接近撞擊會加速並輕微震動。
- 胖子／惡棍需拖入軌道虛線框。錯誤位置會回彈，成功後不可撤回。觸控亦適用。
- 活板門按圓點旁的小型方形機關。
- 醫療關將下方紅叉拖到左側健康的人。右側五位病患以半透明閃爍圓點呈現；手術後停止閃爍，健康的人淡出。
- 空白鍵可操作；Esc 暫停／繼續，離開分頁自動暫停。支援螢幕閱讀器及減少動態效果偏好。
- 十關後顯示四個百分比、三項情境比較与可展開的十關回顧。儲存圖片產生 1440 × 1700 PNG；若沒有自動下載，可使用「再次儲存」。

## 十關

1. 列車長：直行五人／轉向一人。
2. 旁觀者：相同條件，改變角色。
3. 親密對象：親人在直線，不動犧牲一人；轉向犧牲五人。
4. 天橋胖子：拖入軌道擋停列車。
5. 肥胖惡棍：同樣操作，但對象是綁架五人的加害者。
6. 活板門：以機關使胖子墜落。
7. 器官移植：犧牲未同意捐贈的健康人，救五位陌生病患。
8. 熟識病患：五位待救者中有親密對象。
9. 反向預設迴圈：不动犧牲一人擋停電車；操作切回主線，犧牲五人。
10. AI 指令：自駕車自撞犧牲乘客，或維持直行撞上五位行人。

第 3、9 關的相反預設，使「操作」與「減少犧牲」不總是相同。

## 分析與資料

「減少犧牲」是十關選擇較少死者的比例；「手段界線」是六個將人作為手段的情境中拒絕該手段的比例；「主動介入」是最終操作比例；「後段決定」是介入樣本中，最後操作位於決策時間後 40% 的比例。沒有介入樣本時顯示 0%，並說明沒有時間樣本。

此分析是本次選擇的描述，不是心理診斷或經驗證的人格測驗。名字與答案僅在頁面記憶體內，不傳送、不儲存，重新整理即清除。PNG 在瀏覽器本機產生，姓名經跳脫處理。可選 WebMCP 唯讀工具只回傳進度，不包含姓名或選擇。

情境參考 [Judith Jarvis Thomson (1985)](https://doi.org/10.2307/796133) 與 [Stanford Encyclopedia of Philosophy](https://plato.stanford.edu/entries/doing-allowing/)；親密關係、反向預設及 AI 為改編。

`index.html` 是結構，`style.css` 是極簡視覺與動畫，`app.js` 是情境、拖曳、計時、分析與圖片匯出。
