# Trolley — 你的選擇，你的輪廓

白底、黑字、細線、大量留白的電車問題互動網站。使用原生 HTML、CSS、JavaScript，無外部套件與建置步驟。所有資源都在資料夾內，直接以瀏覽器打開 `index.html` 即可遊玩，也可用本機伺服器開啟。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

開啟 http://127.0.0.1:4173。

## 流程

1. 輸入名稱，按 Enter 或右侧的返回鍵符號。
2. 閱讀每關的情境後，點一下畫面或按 Enter。情境不會自動略過。
3. 電車由下往上行駛。每關有 12 秒決策時間；風險情境為 14 秒。沒有畫面上的文字倒數或選項按鈕。
4. 使用下方物件，或不操作。拉桿在列車抵達岔口前可以切換；推人、開啟活板門、踏入軌道是不可撤回的選擇。
5. 列車抵達後以人物淡出呈現結果，無血腥畫面。自動進入下一關的情境說明。
6. 第 10 關結束，顯示名稱、四個百分比指標、選擇軌跡、文字分析及可展開的十關回顧。可重新測試。

操作支援滑鼠點擊、觸控、拖曳、空白鍵。推人向左拖、拉環向下拖、踏步向上拖。Esc 暫停／繼續；離開分頁自動暫停，回來後按「繼續」。手機與桌面均可使用，無需登入。

## 十個情境

| 關卡 | 情境 | 操作 | 核心差異 |
|---|---|---|---|
| 01 | 一與五 | 拉桿 | 經典轉轍器：以一人換五人 |
| 02 | 差距變小了 | 拉桿 | 以一人換兩人 |
| 03 | 沒有比較少 | 拉桿 | 一人對一人，作為／不作為 |
| 04 | 回到原點 | 拉桿 | 經典迴圈：一人的犧牲是擋停電車的手段 |
| 05 | 那個人，你認識 | 拉桿 | 一人是你最親近的人 |
| 06 | 你看不清的支線 | 拉桿 | 主線確定一人，支線 20% 有五人、80% 無人 |
| 07 | 手的距離 | 手掌 | 經典天橋：親手推人擋停電車 |
| 08 | 隔著一個機關 | 拉環 | 活板門造成相同的犧牲 |
| 09 | 他說，讓我來 | 手掌 | 天橋人物明確表示自願 |
| 10 | 最後一個，是你 | 踏步 | 以自己換五人 |

第 06 關的支線是否有人會隨機抽樣一次（20%／80%），但分析只依使用者的風險選擇，不因運氣加減分。

## 分析方式

百分比是本次回答的比例，並非經心理計量驗證的測驗、人口常模、人格診斷或善惡評分。

- 結果取向：8 個確定能以一人換多人的情境中，選擇介入的比例。
- 手段界線：5 個以犧牲作為救人手段的情境中，選擇不介入的比例。
- 主動介入：10 個情境中，最終選擇介入的比例。
- 後段決定：有介入的選擇中，最後操作發生於決策時間後 40% 的比例。沒有介入時顯示 0%，並說明無可計算的時間樣本。

文字分析比較天橋／同意、親近關係與自我犧牲等回答；不把保持不動推論成猶豫。

## 內容參考

經典轉轍器、天橋與迴圈問題参考 Philippa Foot 與 Judith Jarvis Thomson 的倫理思想實驗。其他關卡為本作品的延伸情境。

- [Stanford Encyclopedia of Philosophy — Doing vs. Allowing Harm](https://plato.stanford.edu/entries/doing-allowing/)
- [Stanford Encyclopedia of Philosophy — Intuitionism in Ethics](https://plato.stanford.edu/entries/intuitionism-ethics/)

## 資料與無障礙

名字與答案僅留在當前頁面的記憶體，不傳送、不寫入 localStorage，重新整理即清除。所有名稱文字均經 HTML 跳脫。物件有語義化按鈕、螢幕閱讀器標籤與狀態提示；支援鍵盤及減少動態效果偏好。可選的 WebMCP 只提供 `read_trolley_progress` 唯讀工具，不讀取名字、不代替使用者選擇。未支援此 API 的瀏覽器照常運作。

## 修改

- `index.html`：頁面結構、登入前名稱欄位與中繼資料。
- `style.css`：排版、軌道、物件與響應式樣式。
- `app.js`：十關內容、動畫、選擇鎖定、計時、分析。

无需網路、帳號、後端服務或安裝套件。
